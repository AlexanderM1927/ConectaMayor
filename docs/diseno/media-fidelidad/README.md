# Pantallas y sistema visual

La implementación sigue la dirección del prototipo aportado: turquesa, superficies claras, ilustración de personas mayores, tarjetas redondeadas y módulos diferenciados por color. Se adapta a móvil, tableta y escritorio sin encerrar la interfaz en un dibujo de teléfono.

| Elemento | Decisión |
| --- | --- |
| Identidad | Símbolo `groups`, nombre ConectaMayor y frase «Aprende · Protégete · Conecta» |
| Color principal | Turquesa `#126f74`; se oscureció después de medir el contraste sobre menta |
| Texto | `#24464a`; secundario `#526b70` |
| Superficie/fondo | Blanco y `#f7faf9`; destacados menta `#edf6f3` |
| Tipografía | Roboto distribuida con la app; principal 20 px y ajustes 24/28 px |
| Iconos | Material Icons locales mediante `q-icon`, igual que en `homewithchrist` |
| Módulos | Azul: tutoriales; verde: prevención; violeta: simulador; naranja: evaluación |
| Navegación | Superior en escritorio, inferior en móvil y menú lateral para todas las secciones |
| Interacciones | Botones grandes, preguntas con radios nativos, reintentos y explicaciones persistentes |

Las pantallas ejecutables y sus capturas constituyen el entregable visual de media fidelidad, ya conectado a funciones reales. Ver [índice de capturas](../../evidencias/README.md), [bocetos](../baja-fidelidad/README.md) y [navegación](../../navegacion.md).
