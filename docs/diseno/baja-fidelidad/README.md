# Bocetos de baja fidelidad

[Abrir las nueve pantallas esquemáticas](pantallas.svg).

Los bocetos describen jerarquía y distribución sin color de marca ni imágenes finales. Incluyen Inicio, catálogo de tutoriales, paso interactivo, prevención, ejemplo de mensaje, simulador, evaluación, progreso y ayuda. Las variantes de respuesta y las pantallas de resultado se documentan en el [mapa de navegación](../../navegacion.md) y las [capturas del prototipo funcional](../../evidencias/README.md).

En móvil se priorizan una columna, botones amplios y navegación inferior constante. Los bloques de contenido se convierten en columnas o cuadrículas en escritorio. La imagen de bienvenida se sitúa entre el saludo y la acción principal en móvil y al lado del texto en escritorio.
