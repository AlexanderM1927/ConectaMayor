# Desarrollo de ConectaMayor

- Ejecutar Node y npm únicamente dentro de Docker, usando el servicio `frontend`.
- Ejecutar los comandos Docker Compose desde esta carpeta.
- Mantener la aplicación exclusivamente como PWA, sin backend ni Capacitor.
- Persistir los datos de aprendizaje y preferencias en IndexedDB; Pinia mantiene estado en memoria.
- Seguir la organización del frontend de `homewithchrist`, sin trasladar sus módulos de autenticación o servicios remotos.
- Conservar lenguaje claro, navegación por teclado, zoom habilitado y controles grandes.
